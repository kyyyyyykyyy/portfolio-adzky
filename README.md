## 🔥 Highlight Fitur (AAA Quality)

Portofolio ini bukan sekadar website statis biasa. Ini adalah **Interactive Experience** yang dibangun layaknya video game modern:

* 🌌 **Neural Network Background:** Partikel interaktif yang merespons gerakan mouse (efek jaringan saraf tiruan).
* 🏆 **Gamification Achievement System:** Notifikasi *Pop-up Achievement* ala game console saat user melakukan aksi tertentu.
* 💎 **Neon Profile Card:** Bingkai foto dengan animasi cahaya neon berputar (*CSS Conic Gradient*).
* 🎴 **3D Flip Cards:** Kartu interaktif yang bisa dibolak-balik secara 3D saat di-hover untuk melihat detail skill.
* 🎉 **Confetti Explosion:** Efek ledakan kertas warna-warni sebagai *reward* saat pengunjung mengirim pesan.
* 🏃 **Marquee Running Text:** Teks berjalan parallax yang kecepatannya mengikuti kecepatan scroll user.
* 🖱️ **Custom Gaming Cursor:** Kursor kustom dengan efek *trail* dan magnetik.

## ⚙️ Instalasi & Cara Menjalankan (Local Deploy)

Jika Anda ingin menjalankan project ini di komputer Anda sendiri, ikuti langkah berikut:

### 1. Clone Repository
Buka terminal dan clone project ini:
```bash
git clone [https://github.com/username-kamu/nama-repo.git](https://github.com/username-kamu/nama-repo.git)
cd nama-repo

2. Install Dependencies (Wajib)
Project ini menggunakan beberapa library animasi khusus. Install semuanya dengan perintah:

Bash

npm install
Catatan untuk Developer: Library yang digunakan dalam project ini meliputi:

framer-motion (Animasi)

react-type-animation (Efek ngetik)

react-icons (Icon pack FontAwesome)

react-parallax-tilt (Efek 3D Tilt)

canvas-confetti (Efek ledakan kertas)

react-tsparticles & tsparticles-slim (Background partikel)

3. Jalankan Server Development
Setelah install selesai, jalankan perintah:

Bash

npm run dev
Buka browser dan akses link yang muncul (biasanya http://localhost:5173).
